# Support and questions

This is an independent educational repository, not an official Anthropic support channel.

For questions about the workshop's steps, examples, or expected output, open a GitHub issue using the question template. Include your operating system, Python and `uv` versions, SDK version, the step number, and sanitized error output.

For Claude API account access, billing, outages, and platform-specific support, use Anthropic's official documentation and support channels.

Never post API keys, `.env` contents, sensitive prompts, private session transcripts, or customer data in an issue.
